# Лабораторная работа №1 – Операторы ввода/вывода. Условный оператор

В репозитории находятся три программы:

1. **задание1.py** — калькулятор площади треугольника по формуле Герона  
2. **задание2.py** — конвертер единиц измерения расстояния  
3. **задание3.py** — определение високосного года  

---

## Среда разработки

- **Язык программирования:** Python 3  
- **Среда разработки:** Visual Studio Code / PyCharm / любой редактор с поддержкой Python  
- **Файлы для запуска:** `задание1.py`, `задание2.py`, `задание3.py`

---

## Инструкция по работе

### Задание 1. Калькулятор площади треугольника

1. Откройте файл `задание1.py`.
2. Запустите программу.
3. По запросу введите три стороны треугольника (целые или дробные числа).
4. Программа выведет площадь треугольника с точностью до сотых.

**Пример:**
Введите сторону a: 5.5
Введите сторону b: 6.2
Введите сторону c: 7.1
Площадь треугольника: 16.43


---

### Задание 2. Конвертер единиц измерения расстояния

1. Откройте файл `задание2.py`.
2. Запустите программу.
3. Выберите исходную единицу измерения (км, м, см, мм, mi, yd).
4. Выберите целевую единицу измерения.
5. Введите числовое значение.
6. Программа выведет результат конвертации.

**Поддерживаемые единицы:** км, м, см, мм, mi, yd

---

### Задание 3. Определение високосного года

1. Откройте файл `задание3.py`.
2. Запустите программу.
3. Введите год (целое число).
4. Программа определит, является ли год високосным, по правилам:
   - год делится на 4;
   - если год делится на 100 — не високосный;
   - если год делится на 400 — високосный.
